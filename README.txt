Kritikalajewels POS PWA v3

This version is installable as a PWA when hosted on HTTPS.
It uses the phone camera through the browser's BarcodeDetector API for Code 128/EAN/UPC/QR scanning where supported.

Demo products: KJ001-KJ005.
Workflow: camera scan -> product -> MRP -> enter actual selling price -> quantity -> bill -> payment -> stock deduction.

Important: camera access generally requires HTTPS and browser support. For production, host this folder on an HTTPS web host. Data is stored locally in the browser; use Export Backup regularly.
